# 平置き3cm 推定チェッカー

`index.html` をブラウザで開くと使えます。外部ライブラリやサーバーは不要です。

- Amazonで厚さ3cm超と掲載される袋商品を中心に、100 ASINを収録
- 内容量、粒や粉のかさ密度、袋の平面寸法から、均した後の厚さを概算
- 「収まりそう」「境界・情報不足」「難しい」に分類し、検索・絞り込み可能
- 各商品に厚さの目安、確信度、仮定、参考リンクを表示
- 全件を予測と根拠つきのCSVとして出力可能
- 商品袋の実寸と梱包後の最大厚をブラウザに記録し、CSVに含められる

数値は実測値ではありません。梱包サイズを袋の平面寸法の代わりに使った商品や、かさ密度・内容質量を近似した商品は確信度を下げています。特に個包装、袋のマチ、付属スプーン、硬い注ぎ口は内容物の体積計算だけでは判定できません。元の例 `B00TXC7RBG` は100件に含めていません。

Amazonの梱包寸法や他商品の袋寸法しかない場合、計算値が3cmより薄くても「境界・情報不足」に分類します。これは見逃しを増やす代わりに、根拠の弱い「収まりそう」を減らすためです。

推定を更新する場合は `build_predictions.py` の個別補正と密度範囲を修正し、`python3 build_predictions.py` で `predictions.js` を再生成します。

精度を評価するには、各商品を実際の発送状態にして最も厚い箇所を測り、商品袋の幅・長さとともに記録します。予測と実測の差を分類ごとに確認してから補正してください。実測データがない段階では、画面の「確信度」は統計的な的中率ではありません。
