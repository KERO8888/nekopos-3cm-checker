# ネコポス・クリックポスト 寸法チェッカー

`index.html` をブラウザで開くと使えます。外部ライブラリやサーバーは不要です。商品写真と寸法根拠は最初に見える商品詳細の主画面に配置し、商品写真は `assets/product-images/` に保存した113件を優先して表示します。

`acquisition.html` はデータ取得状況のページです。直近の新規調査で見つけた件数、商品ページ確認数、追加数、検索語ごとの記録、追加商品の一覧反映、画像・Keepa・予測データの取得状態を表示します。保存済みデータの状態であり、ページを開くだけで新しい検索やAPI取得は実行しません。商品分析画面の「データ取得状況」から開けます。

- 自己消費できる食品・飲料・入浴剤・日用品の113 ASINを収録。2026年10月11日にペット用食品39件と園芸資材1件を候補から外し、入浴剤4件、ボディソープ4件、化粧水・乳液・クレンジング6件の単品詰め替え袋を追加。10月12日に薬用泡ハンドソープの単品詰め替え袋を1件追加。除外したASINは `excluded_products.json` に記録
- 内容量、粒や粉のかさ密度、袋の平面寸法から、均した後の厚さを概算
- 商品袋の縦横に外装余白を加え、長辺・3辺合計・厚さ・重量をネコポスとクリックポストで別々に判定
- メーカー公式の同一商品寸法を優先し、Amazon・Keepaの本体寸法、カタログのパッケージ寸法、同系品の仮定を区別
- 「概算内・要実測」「要実測」「規格外」「実測値は規格内」で配送方法ごとに表示・絞り込み可能
- 各商品に厚さの目安、確信度、仮定、参考リンクを表示
- Amazonの商品ページから取得した商品画像URLを使って写真を表示
- 選択中の商品にKeepaの価格履歴グラフを表示（読み込みに失敗した場合はKeepaへのリンクを表示）
- 選択中の商品に推定根拠、Keepa APIの掲載寸法、実測記録欄を表示
- 全件を予測と根拠つきのCSVとして出力可能
- 商品袋の幅・長さ、梱包後の外装長辺・短辺・最大厚・重量をブラウザに記録し、CSVに含められる
- ネコポスとクリックポストの現行規格・運賃を公式リンク付きで表示
- 各商品に縮尺のない商品写真を全体表示し、縦横の模式図と厚みの定規を並べて表示。袋寸法や厚みの推定値は実測値と区別して表示
- 確認済みの仕入先・価格と、送料・手数料を含む自社発送の1点利益を表示。未確認品は価格入力で試算

画面は左の商品一覧、中央の商品写真・縦横の模式図・厚みの定規、右の配送判定と概算利益を一画面に配置しています。初期表示は「黒字候補」の利益順で、商品を選ぶと各欄が切り替わります。左欄で黒字候補・参考試算・仕入先未確認・売価未取得・登録済みを切り替え、黒字候補だけをCSVに保存できます。「登録済み」はAmazon全商品を意味しません。寸法根拠、価格入力、実測欄、Keepaグラフは「利益の内訳・実測入力・判定根拠を見る」にまとめました。

推定値は実測値ではありません。商品の袋と発送用の外装は別に扱います。粉・粒は内容量とかさ密度から体積を見込みます。液体のmL表示はすでに体積なので密度で割りません。外装の縦横に各0〜2cm、重量に100gを仮に加えて発送判定します。梱包資材や詰め方によって変わるため、最終確認は梱包後の外寸・重量とクリックポストの投函口で行います。個包装、袋のマチ、付属スプーン、硬い注ぎ口は内容物の体積計算だけでは判定できません。元の例 `B00TXC7RBG` は候補に含めていません。

公式規格（2026年10月6日確認）：[ネコポス](https://business.kuronekoyamato.co.jp/service/lineup/nekoposu/index.html)は長辺34cm以内・3辺合計60cm以内・厚さ3cm以内・1kg以内、宛名面23×11.5cm以上。利用には契約が必要で、運賃は契約ごとに決まり、公式上限は385円です。[クリックポスト](https://www.post.japanpost.jp/service/send/domestic/delivery/clickpost/)は全国一律240円、長辺34cm以内・3辺合計60cm以内・2kg以内、最小14×9cm、ポストに投函可能なこと。厚さ3cmは投函の目安で、郵便局窓口で差し出せる例外でも3cm以下です。横幅25cmという固定上限は公式ページにありません。

2026年10月9日に、当時収録していた140件をYahoo!ショッピングで商品コードまたは商品名から検索し、商品ページ候補のURL 749件を照会しました。単品・JAN一致・在庫・価格を条件に98商品183仕入先を照合しました。10月11日にJAN付き未照合商品の検索下位候補202ページを追加照合しましたが、同条件での一致は増えませんでした。新規商品もJANで検索し、メーカー公式サイトで200g×1袋・税込2,916円・国内送料660円を確認しました。Yahoo!ショッピングでは2仕入先の送料が未確認のため利益計算に使いません。10月12日のハンドソープ350mLはJAN 4573388510158でYahoo!ショッピングの在庫あり単品2仕入先を確認し、最安は商品737円＋東京都向け送料540円でした。これらは一部サイトの検索結果と個別ページの調査であり、全仕入先や全出品を網羅した意味ではありません。別途、ヨドバシ.comの「きき湯ファインヒート ほぐしオフ つめかえ用500g」と「スマートモデル つめかえ用500g」を商品名・容量（後者は香りも）で照合しました。ヨドバシ側の商品コード一致は未確認のため、JAN一致と同等の確信度はありません。

Amazon SP-APIで2026年10月12日に現行113 ASINの新規出品を照会しました。自己発送の出品価格と購入者送料を別々に取得できたのは77件、自己発送がなくFBA出品価格を参考試算に使うのは36件です。追加した1件も自己発送とFBAの価格を取得済みです。FBAのおすすめ出品が安い場合、高値の自己発送価格で黒字でも販売可能な利益品とは扱いません。

利益は「自己発送の出品価格＋購入者送料−付与ポイント−仕入価格−仕入送料−発送運賃−梱包材費−Amazon自己発送手数料」で概算します。FBA配送代行手数料は差し引きません。クリックポストは240円、ネコポスは契約運賃の入力後に計算します。梱包材費20円は編集可能な初期仮定です。仕入先が未照合でも売価があれば、利益が0円になる仕入上限を表示します。現行113件の内訳は黒字候補2件、FBA価格による参考試算16件、価格差に注意が必要な黒字2件、赤字59件、仕入条件未照合34件です。発送できるかは梱包後の実測値で確認します。

黒字の計算例は、ほぐしオフ500g（B0DQDTBXJ7）のAmazon自己発送出品1,834円・購入者送料0円・付与18pt、ヨドバシ.com仕入880円・送料無料、発送240円、梱包20円、Amazon手数料見積もり191円＋税20円から、1点**＋465円**です。スマートモデル500g（B093DGHBXC）は、10月11日のヨドバシ.com仕入770円・送料無料と、10月12日にSP-APIで再照会したAmazon自己発送出品1,277円・購入者送料0円、発送240円、梱包20円、自己発送手数料107円＋税11円を組み合わせると**＋129円**です。仕入先は商品名・香り・容量で照合し、商品コード一致は未確認です。いずれも厚み予測2.8〜3.7cmの低確信度候補で、梱包後3cm以内は未確認です。前者はAmazon側のJAN未確認、後者はおすすめ出品価格が取得できず、実際に販売できる利益額ではありません。購入や出品は行っていません。

商品写真は縦横の寸法図に重ねず、全体を縮尺なしで表示します。寸法図は掲載値や仮定値を数値比で描いた模式図であり、画面上の実寸大ではありません。メーカー公表・入力実測・掲載値からの仮定を明記します。厚みの定規は全商品に表示しますが、未測定の商品は計算上の厚さ範囲を帯で示し、梱包後最大厚の実測値とは区別します。中身を片寄らせず1袋を平置きする手順も示し、最終確認は梱包後の実測値で行います。

[AmazonのSP-API資料](https://developer-docs.amazon.com/sp-api/lang-en_EN/docs/manage-product-listings-guide)では `item_dimensions` と `item_package_dimensions` が別項目で、後者は販売単位の包装寸法です。パッケージ寸法はFBA納品に使う外箱を一律に指すわけではありません。登録情報の誤りや製品改訂、Amazonの計測状態による差があるため、平置き時の発送外寸としては採用しません。

新規登録の目安は「人が食べる・飲む、入浴や日用品として自己消費できる」「柔らかい袋に入った液体・粉・粒など、ならして薄くできる内容物」「Amazon掲載の3辺寸法の最小辺が3cm超」「袋の有効面積と内容量から、平置き後に3cm以下となる可能性がある」の4点です。ペット用食品と園芸資材、硬い容器、付属品やキャップで3cmを超えそうな商品、複数個を重ねるセットは登録しません。商品袋ではなく梱包寸法しかない場合は、薄く計算されても判定を保留します。既存候補には旧基準の寸法未確認・厚さが難しい調査候補も残っています。

2026年10月12日時点で、Amazon.co.jp内の28検索語から重複を除いた906 ASINを記録し、422 ASINの商品ページを確認しました。484 ASINと後続の検索結果ページは未確認です。調査履歴上の追加は56件で、現在の候補一覧は自己消費できる商品113件です。この日はハンドソープ検索の未確認35件を照合し、単品の切り口付き詰め替え袋 B06XKT5RLJ を1件追加しました。Amazon掲載は梱包寸法21×9×5cmのみで、350mLという内容量に対する掲載重量200gは整合しません。このため推定の確信度は低く、梱包後最大厚と重量の実測まで発送可否は未確定です。残りの照合品は複数個、硬いボトル、キャップ付きパウチ、大容量、掲載最小辺3cm以下などで除外しました。ハンドソープ250mL検索の35表示候補はASIN記録と個別ページ確認が未完です。検索語・ASINごとの進捗は `research_progress.json`、除外品は `excluded_products.json` に保存しました。Amazon上の全商品を確認した意味ではありません。

メーカー公式で同一商品の寸法を確認した11件は `manufacturer_dimensions.json` に出典とともに記録しました。GEXの「個装サイズ」とAGFの「単品サイズ」は、袋の面と通常時の奥行・重量を分けて使います。通常時の奥行は平置き時の厚さではありません。Amazonの梱包寸法や他商品の袋寸法しかない場合、計算値が薄くても発送判定は「要確認」にします。

推定を更新する場合は `manufacturer_dimensions.json` と `build_predictions.py` の個別補正・密度範囲を修正し、`python3 build_predictions.py` で `predictions.js` を再生成します。規格判定は `shipping_fit.js`、利益計算は `finance.js` にあります。`node test_shipping_fit.js`、`node test_finance.js`、`node test_market_data.js`、`node test_profit_ui.js` で境界条件、費用、価格データの整合、利益区分、CSVを確認できます。

新規調査で `research_progress.json` と `data.js` を更新した後に `python3 build_predictions.py` を実行すると、取得状況ページ用の `acquisition_status.js` も再生成されます。調査記録だけを更新した場合は `python3 build_acquisition_status.py` で再生成できます。画像とAPIの件数は、それぞれの保存済みJavaScriptからページ表示時に集計します。

SP-API と Keepa API の寸法は `sync_api_dimensions.py` で取得し、認証情報を除いた `api_dimensions.js` に保存します。未取得時は画面に理由を表示します。この端末ではコジマネットアウトレットリサーチツールと同じmacOSキーチェーン項目を自動で読みます。別の環境では環境変数 `SP_API_CLIENT_ID`、`SP_API_CLIENT_SECRET`、`SP_API_REFRESH_TOKEN`、`KEEPA_API_KEY` または `--env-file /absolute/path/to/secrets` を使えます。認証情報はこのプロジェクト内やブラウザ用JavaScriptに保存しません。Keepaは取得したASIN数に応じてAPIトークンを消費するため、SP-APIだけ再取得するときは `python3 sync_api_dimensions.py --sp-only` を使います。

2026年10月5日の取得ではKeepa APIから135件の応答を保存しました（3辺がそろう商品寸法55件、パッケージ寸法131件）。このツールは別プログラムの「手数料取得用」SP-APIアプリの認証情報を流用しています。同アプリでは手数料APIの取得記録がありますが、LWAトークン取得成功後もCatalog ItemsはHTTP 403でした。[Amazonの権限資料](https://developer-docs.amazon.com/sp-api/docs/roles-in-the-selling-partner-api)ではCatalog ItemsにProduct Listingロールが必要で、手数料APIに使用できるPricingロールとは別です。手数料アプリにProduct Listingロールが付いているか、開発者プロフィールとアプリ登録、再認可したリフレッシュトークンを確認する必要があります。ロールの実際の設定はSeller Centralで未確認のため、403の直接原因はまだ確定していません。

APIに掲載される「商品寸法」「パッケージ寸法」は、発送用に中身を均した状態の実測厚とは別です。画面上でも出典を分けています。Keepaの商品寸法はメーカー寸法やAmazonの商品寸法がないときに袋面の手がかりとして使います。パッケージ寸法しかないときは袋面の仮置きにとどめ、発送可能とは判定しません。

商品画像の元URLは `product_images.js` に保存されています。`python3 cache_product_images.py` で商品写真を縮小して `assets/product-images/` に保存し、`local_product_images.js` を作成できます。新しいASINのURLを取得する場合は `python3 fetch_product_images.py` を実行してからキャッシュを更新してください。現在は113件すべてをローカル保存済みです。Keepaグラフは外部表示が使えない場合、各商品のKeepaリンクから確認できます。

`assets/ui-design-reference-v7.png` は、商品写真・縦横の模式図・厚みの定規を3枚のカードで見せる画像生成UI案です。数字・商品描写・配送規格は見本であり、実データには採用していません。商品写真は全体を `contain` で表示し、寸法図に重ねません。縦横図は数値比の模式図で、**画面上の実寸大ではありません**。掲載寸法から袋寸法を仮定した場合は警告を表示します。厚みの定規には計算範囲と3cmの線を描き、梱包後の実測値と明確に区別します。外装サイズの概算数値は発送可否の保証ではありません。配送サービスの目印は、各公式サイト掲載のロゴ画像の左端にあるマーク部分を画面上で切り出して表示し、サービス名を文字で併記します。ヤマト運輸のロゴは[ネコポス公式ページ](https://business.kuronekoyamato.co.jp/service/lineup/nekoposu/index.html)、クリックポストのサービスロゴは[専用公式サイト](https://clickpost.jp/)から取得しました。

`assets/ui-profit-reference-v1.png` は利益品抽出用の画像生成UI案です。左欄の利益区分、利益順、候補の利益額、選択商品の収支を現行画面へ反映しました。画像案の架空の商品写真・寸法・運賃・料率は実データに採用していません。

今後UIを変えるときは、画像生成で新しい画面案を先に作り、商品写真・寸法・利益などの事実と見本画像内の架空表現を分けてから実装します。実装後はアイコン、画像、定規の比率、文字の可読性、横幅のはみ出し、商品を切り替えた際の表示、モバイルの配置を確認します。

精度を評価するには、各商品を実際の発送状態にして外装の長辺・短辺・最大厚・重量を測り、商品袋の幅・長さとともに記録します。予測と実測の差を分類ごとに確認してから補正してください。実測データがない段階では、画面の「確信度」は統計的な的中率ではありません。
