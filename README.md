### 仕入先探索の改修（2026年10月13日）

10月13日の再点検で、EPSOPIA（B0997R1575）はAmazon側の「600g＋増量200g」に計量スプーンも付く販売単位と判明しました。メーカーも通常600gとAmazon向け増量品を区別しています。柔らかい単品袋の登録条件を満たす根拠がないため主一覧から除外し、調査履歴と除外理由を保存しました。仕入先ページの600gだけを増量品の仕入れとして誤採用しないよう、複数の内容量表記とURL中のJANの矛盾も照合するよう修正しました。[メーカーの説明](https://epsopia.happy-adwords.co.jp/blog/4833/)

旧工程はYahoo!ショッピングのJAN検索を主とし、仕入先が見つかったASINの追加検索を止め、最安6ページ・最大2仕入先だけ照合していました。このため、JANが検索索引に入らない楽天商品や、アスクルなどの一般店を取りこぼしていました。改修後は `discover_supplier_leads.py` で各ASINの商品名とJANを楽天・Yahoo!ショッピングの両方で検索し、重複、表示価格、東京都向け表示送料、表示ポイント、クーポンの有無を記録します。検索結果は未照合候補であり、仕入先確定数には含めません。`verify_rakuten_suppliers.py` は商品ページのJAN、単品、税込価格、在庫を照合し、商品ページの価格が検索結果と一致し、検索結果に東京都向け送料が明示されたものだけ利益計算の仕入先に追加します。KeepaにJANがない場合は、商品名・容量が合い、異なる2店舗の商品ページで同じJANを確認できたときだけ店舗間照合として登録し、Amazon側JANとの一致とは区別します。一般検索で見つけた店舗も個別の商品ページと送料規定を調べ、注文条件が不明な割引は利益に加えません。

商品写真は縦横の寸法図に重ねず、全体を縮尺なしで表示します。寸法図は掲載値や仮定値を数値比で描いた模式図であり、画面上の実寸大ではありません。メーカー公表・入力実測・掲載値からの仮定を明記します。厚みの定規は全商品に表示しますが、未測定の商品は計算上の厚さ範囲を帯で示し、梱包後最大厚の実測値とは区別します。中身を片寄らせず1袋を平置きする手順も示し、最終確認は梱包後の実測値で行います。

[AmazonのSP-API資料](https://developer-docs.amazon.com/sp-api/lang-en_EN/docs/manage-product-listings-guide)では `item_dimensions` と `item_package_dimensions` が別項目で、後者は販売単位の包装寸法です。パッケージ寸法はFBA納品に使う外箱を一律に指すわけではありません。登録情報の誤りや製品改訂、Amazonの計測状態による差があるため、平置き時の発送外寸としては採用しません。
